🧹 Limpiar datos de prueba

Si hiciste ventas de prueba, puedes eliminar solo el historial de ventas. Tus productos, cantidades, fotos y clientes no se borrarán.

Los reportes de ingresos, costos y ganancias quedarán en $0 porque se calculan a partir de las ventas.

🧹 Borrar productos, ventas y clientes

Elimina únicamente productos, ventas y clientes de esta cuenta. No elimina pedidos web, proveedores, gastos, movimientos ni categorías. Esta acción no se puede deshacer.
